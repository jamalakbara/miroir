Chosen from the 'Font Pairs' board in miroir.pen (5 free Google Font pairs).

Fonts the reference sites actually serve (read from computed styles, 2026-10-31): zara.com Helvetica Now Text 300 at 13px (+ a Didone serif for brand); shopatvelvet.com Helvetica Light + a Letter Gothic-style mono ('gothicM'); cos.com Suisse Int'l; lemaire.fr Brown + Garamond; ourlegacy.com Neue Haas Unica. All paid, so free look-alikes were used.

Applied via the pen variables font-sans = Inter Tight, font-mono = DM Mono. Every page text uses these tokens; only the Font Pairs board hardcodes fonts.

Rejected: Inter Tight + Bodoni Moda (pure Zara, loses velvet's mono feel), Geist + Geist Mono (too tech), Hanken Grotesk + EB Garamond and Instrument Sans + Instrument Serif (warmer and more boutique than wanted).
