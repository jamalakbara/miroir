01

About this guide.

This guide shows the Miroir team how to run miroir.id day to day without a developer: signing in, finding your way around the dashboard, handling WhatsApp orders, and keeping products, pages and campaigns up to date.

Each task is written as short, numbered steps. Menu and button names, such as Publish, match the labels you see on screen. If something does not look the way this guide describes, check the troubleshooting chapter first, then contact me.

ReaderRead these chapters

Store admin

Owner or ops lead. Every chapter.

Content / marketing

Chapters 04 Dashboard, 05 Pages, 07 Products, 08 Header & settings, 09 Prices & SEO.

CS / order handler

Chapters 06 WhatsApp orders and 07 Products.

How to read it

Read chapters 02 and 03 once. Use the rest as a reference per task, for example "I want to change a banner" → 05.5. Menu paths are written as Menu → Submenu → Tab. Warnings mark risky actions: deleting, maintenance mode and exchange rates. Plugin versions at the time of writing: WooCommerce 11.2, Elementor 4.3, WooCommerce Multilingual 5.6.

02

System overview.

The one rule to remember

Code (the Miroir theme and plugins) flows one way: local → staging → live, and only the developer sends it. Content (products, orders, pages, photos, settings) stays on each site and is never copied. Edits made on staging never appear on live.

03.6

Account security

  • Passwords of at least 12 characters, unique, kept in a password manager. Customer accounts also need 12 characters.
  • One account per person. Never share an Administrator login. Log out on shared computers.
  • Two-factor authentication is recommended for Administrators; arrange it with the developer (11.3).
  • Review Users every month: remove unused accounts, check for unknown Administrators.
  • Emails asking you to log in or "verify your WordPress/Hostinger account" via a link are suspicious. Type the address yourself.

05

Pages & home page.

Every page is built from Miroir widgets. You change widget content (images, text, links, options), not the layout, so the design stays as intended.

05.1

How Miroir widgets work

  1. 01

    Open Pages → All Pages, hover over the page → Edit with Elementor.

  2. 02

    Click the section on the canvas. Its settings open in the left panel.

  3. 03

    Change the content, then check desktop, tablet and mobile in Responsive mode.

  4. 04

    Press Update. The change is live immediately.

  • Miroir widgets sit in the Miroir category. Colours, spacing and fonts come from Site Settings (08), not the widget.
  • Many widgets have a Show switch for optional parts, and a Texts section for that widget's small labels.
  • An empty image field uses a fallback, as described under the field.

Pages → All Pages. Hover a row for Edit with Elementor.

Text pages

FAQ, size guide, policies, contact, shipping and payment confirmation keep their text in the Text page widget, not the regular page editor.

  1. 01

    Edit the Text field: headings, bold, lists and links like in Word.

Each question is an expand/collapse block. Open the Text (code) tab, copy an existing question block with its answer, then change the words. Questions typed freely in the Visual tab will not expand and collapse.

06

WhatsApp orders.

The site does not take payments. Customers send their order by WhatsApp, the order is saved in WooCommerce, and payment (bank transfer or PayPal) is confirmed in the chat. This chapter is the CS team's daily SOP.

WhoFlow

Customer

Choose product and size → Bag (qty, coupon) → Review (delivery details, send) → Order sent page + WhatsApp opens with the message.

Store team

Match the Order ref in Orders → send payment details → check proof, set Processing → ship, add tracking, set Completed.

The order is recorded the moment the customer presses send on Review. Everything after happens in the chat and ends with a status update in WooCommerce.

06.1

What the customer sees

  1. 01

    Chooses a product and size, then Add to bag or Order via WhatsApp (both go to the bag).

  2. 02

    In the Bag: sets quantities, can enter a coupon code.

  3. 03

    On Review: full name, phone, country, address, postcode, province, city, optional email and notes.

  4. 04

    Presses send. The order is saved in WooCommerce right away and the bag is emptied.

  5. 05

    The Order sent page opens with summary, address, bank account, PayPal and a button to reopen WhatsApp. WhatsApp opens with the message filled in.

06.3

Daily SOP: processing a new order

  1. 01

    Receive the chat

    Open the new chat in WhatsApp Business and note the Order ref.

  2. 02

    Find the order

    WooCommerce → Orders, search the ref, open it. New orders are On hold.

  3. 03

    Check the contents

    Compare products, sizes, quantities and address with the chat. If they differ, follow WooCommerce or edit the order with the customer (06.5).

  4. 04

    Confirm stock and shipping

    Check availability, calculate shipping, send the final total in the chat.

  5. 05

    Send payment details

    Bank or PayPal, as on the Order sent page. Add shipping to the order (06.5) so the totals match.

  6. 06

    Check the payment

    When funds arrive, set the status to Processing and keep the proof as a private note.

  7. 07

    Ship

    Add courier and tracking number as a note to the customer, send it in the chat, set Completed.
