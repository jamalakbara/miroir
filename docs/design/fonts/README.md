# Design fonts (local only)

`miroir.pen` loads Avenir from this folder:

- `Avenir-Roman.ttf` (400)
- `Avenir-Medium.ttf` (500)

Avenir is a licensed Linotype font, so the files are gitignored and must be
supplied on each machine. On the Mac they live in
`~/Library/Application Support/miroir/design-fonts/`. Do not deploy or
redistribute them as website assets.
